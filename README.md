# سایت تعمیر گیربکس اتوماتیک (Next.js، استاتیک)

## اجرا
```bash
npm install
cp .env.example .env.local   # آدرس واقعی دامنه را در NEXT_PUBLIC_SITE_URL بگذارید
npm run dev                  # توسعه
npm run build                # خروجی استاتیک در پوشه‌ی out
npm start                    # پیش‌نمایش خروجی ساخته‌شده روی http://localhost:3000
```

توجه: `next start` با خروجی استاتیک کار نمی‌کند؛ برای پیش‌نمایش از `npm start` (که `serve` را روی پوشه‌ی out اجرا می‌کند) یا برای توسعه از `npm run dev` استفاده کنید.
پوشه‌ی `out` را روی هر هاستی (cPanel، Nginx، Netlify، Vercel، Cloudflare Pages) آپلود کنید. بک‌اند لازم نیست.

## قبل از انتشار حتماً ویرایش کنید
فایل `src/lib/site.ts`: نام کسب‌وکار، تلفن، واتساپ، آدرس، ساعت کاری، مختصات و لینک نقشه.
همچنین `NEXT_PUBLIC_SITE_URL` (دامنه‌ی واقعی) و در صورت نیاز `NEXT_PUBLIC_GSC_VERIFICATION` برای سرچ کنسول.

## ویرایش محتوا
- خدمات: `src/content/services.ts`
- علائم خرابی: `src/content/problems.ts`
- برندها: `src/content/brands.ts`
- مقالات: `src/content/articles.ts`
- سؤالات متداول صفحه‌ی اصلی: `src/content/faq.ts`

افزودن یک آیتم جدید به هر فایل، صفحه، سایت‌مپ و داده‌ی ساختاریافته‌ی آن را خودکار می‌سازد.

## بعد از انتشار
1. `sitemap.xml` را در Google Search Console ثبت کنید.
2. پروفایل Google Business را با همان نام، آدرس و تلفن بسازید.
3. عکس واقعی کارگاه و نظرات مشتریان واقعی اضافه کنید؛ برای رتبه‌ی محلی اثر زیادی دارد.

## گیربکس سه‌بعدی در هیرو
- فایل‌ها: `src/components/HeroStage.tsx` (بارگذاری تنبل) و `src/components/gearbox-scene.ts` (صحنه‌ی three.js).
- مدل یک مجموعه‌ی سیاره‌ای (Planetary gearset) کاملاً پروسیجرال است و فایل مدل ندارد. تعداد دندانه‌ها، رنگ‌ها و سرعت چرخش را بالای همان فایل می‌توانید تغییر دهید.
- فقط بعد از بیکار شدن مرورگر بارگذاری می‌شود. اگر WebGL نباشد، «صرفه‌جویی داده» روشن باشد یا کاربر حرکت کم را انتخاب کرده باشد، تصویر ثابت یا صحنه‌ی بدون حرکت نمایش داده می‌شود.
- برای حذف کامل: `<HeroStage />` را از `src/app/page.tsx` بردارید.

## عکس‌های واقعی (اختیاری)
کارت خدمات تا وقتی عکس ندارید از تصویرسازی خطی استفاده می‌کند. عکس را در `public/images/` بگذارید و مسیرش را در `src/content/media.ts` بنویسید.

## طراحی
همه‌ی رنگ‌ها توکن CSS در بالای `src/app/globals.css` هستند (`--accent` نارنجی، `--bg` زمینه). بخش روشن صفحه‌ی اصلی با کلاس `.theme-light` همان توکن‌ها را برمی‌گرداند.

## سئو: چک‌لیست بعد از انتشار
- `src/lib/site.ts`: نام، آدرس، تلفن و ساعت کاری باید دقیقاً با پروفایل Google Business یکسان باشد (NAP). `geo` (مختصات) و `social` (لینک اینستاگرام و ...) را هم پر کنید.
- `NEXT_PUBLIC_SITE_URL` را دامنه‌ی واقعی بگذارید و `sitemap.xml` را در Search Console ثبت کنید.
- `src/content/reviews.ts`: فقط نظر واقعی مشتریان را بنویسید. خالی باشد، بخش نظرات نمایش داده نمی‌شود. برای نظرات خودتان اسکیمای امتیاز اضافه نکنید (گوگل آن را نمی‌پذیرد).
- آدرس نقشه (`mapsUrl` در `site.ts`) را به لینک واقعی مکان تعمیرگاه در نقشه تغییر دهید.
- عکس واقعی کارگاه را با نام توصیفی در `public/images/` بگذارید و در `src/content/media.ts` ثبت کنید.
